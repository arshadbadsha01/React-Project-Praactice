How to delete commit in github?
1: Soft Reset (Sirf Commit delete hoga, Code safe rahega)
   *1. Local machine par latest commit ko delete karein
        git reset --soft HEAD~1

   *2. GitHub par changes ko update (push) karein
        git push origin main --force

2: Hard Reset (Commit aur Code dono poori tarah delete ho jayenge)
    *1. Local machine se commit aur code dono ko saaf karein
        git reset --hard HEAD~1
    *# 2. GitHub par force push karke wipe out karein
        git push origin main --force

1. Calculator app ka APK Bhana ne ke liye hum Android Studio app ka istemal karre hai
  *Step 1:Capacitor install karo
     npm install @capacitor/core @capacitor/cli
     npx cap init
  *Step 2: Android platform add karo
    npm install @capacitor/android
    npx cap add android
  *Step 3: Apna React app build karo
    npm run build  -  Ye ek dist folder banayega jisme tumhari final, optimized website files hongi.
  *Step 4: Build ko Capacitor mein sync karo
    npx cap sync
  *Step 5: Android Studio mein kholo
    npx cap open android  -  Ye automatically Android Studio kholega tumhare project ke saath.
  *Step 6: Android Studio se APK banao
    Android Studio ke andar:
     1. Top menu se Build → Build Bundle(s) / APK(s) → Build APK(s)
     2. Thoda wait karo (compile hone mein time lagega)
     3. Ek notification aayegi "APK generated" — usme "locate" click karo
     4. Tumhari .apk file mil jayegi (usually app/build/outputs/apk/debug/ folder mein)
